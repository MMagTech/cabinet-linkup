# Security

**Report a security problem privately**, not in a public issue: on this repository's Security
tab, choose "Report a vulnerability". It stays between you and the maintainer until he
publishes it.

A security problem is anything that lets someone reach what they should not: pairing without a
code, posing as a server or a console, reading what is sealed between two consoles, using a relay
without a password for a game, reaching an owner's home network through the relay, or getting into
the admin page.

Say which version (the admin page, Server, Settings, Version) and how to make it happen. Leave the
data folder out of the report: it holds keys.

Only the latest version gets fixes. A fix ships as a new version, the admin page shows an update
notice, and owners are told. Nobody can be forced to update.
